# webisteportalberita
Portal Berita adalah aplikasi website berita yang dirancang untuk menyediakan informasi secara cepat, terstruktur, dan mudah diakses oleh pengguna. Website ini memungkinkan pengelolaan dan publikasi berbagai artikel berita berdasarkan kategori, sehingga informasi dapat disajikan secara lebih rapi dan informatif.
